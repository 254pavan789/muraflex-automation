✨ AI reading — Claude

–Raster and scanned pages are read by Claude; vector pages use the exact text and only ask AI to fill gaps.

Claude only reads the values. The app's own rules still do the calculations, and every AI value is checked against OCR. If the two disagree, the value is flagged REQUIRES HUMAN REVIEW.

AI settings can only be changed on the PC that runs the app.

Easiest set-up: put a file named key.txt containing the key next to run_app.bat — AI switches on by itself. The key stays on the host PC and is never shown or sent to other PCs. With AI on, page images go to the Anthropic API: check this is allowed for your client drawings.

Use MURAFLEX AUTOMATION on other PCs

Anyone on the office network can open this link in Chrome or Edge – nothing to install. This PC must stay on with the app window open.

If another PC cannot open it, run allow_network_access.bat once on this PC (right-click › Run as administrator).
